# Comprehensive Implicit State Machines Audit and Tri-Perspective Optimizations

- **Task:** Identify every implicit state machine in the Waktu Sejak app and implement architectural changes optimizing UX, DX, and AX simultaneously without breaking existing behaviour.
- **Key files changed:** `i18n.js` (URL param sync, DOM data attributes, `i18n:change` event, `window.__APP_STATE__.i18n`); `index.html` (mobile nav explicit state, body scroll lock, active section ScrollSpy with `IntersectionObserver`, accessible skip link and `main#main-content tabindex="-1"`, App Store interactive feedback notice, `data-store` attributes, agent interfaces); `privacy-policy/index.html` and `terms-of-service/index.html` (skip link, `tabindex="-1"` on main, dictionary synchronization); `tests/state-machines.test.js` (regression suite expanded to 7 tests); `plans/2026-11-18-implicit-state-machines-improvements.md` (roadmap and plan tracking).
- **Decisions:** Made 5 state machines fully explicit: (1) i18n lifecycle with `readUrlLang` and `syncUrl` via `history.replaceState`, (2) Mobile nav drawer with `data-state="closed|open"`, `aria-hidden`, and mobile body scroll lock, (3) Platform store availability with `data-store`, `role="region"`, and polite notice microcopy, (4) Active section ScrollSpy tracking `#features`, `#screens`, `#accessibility`, `#download` with `aria-current="true"` and `data-active-section`, and (5) Skip navigation link focus with `main#main-content tabindex="-1"` across all pages. Expose `window.__APP_STATE__` for deterministic agent testing.
- **Assumptions and risks:** Preserves vanilla zero-dependency architecture. `history.replaceState` avoids polluting browser back history. Scroll lock is scoped strictly to `@media (max-width: 768px)` preventing desktop layout shift. Preserved LF line endings for `index.html` and `privacy-policy/index.html`, and CRLF for `terms-of-service/index.html`.
- **Blockers/open items:** Browser visual verification on real physical mobile device.
